# fuzzbench-results

Records of fuzzbench results executed on private resources, to supercede fuzzbench.com temporarily.
Each report will be submitted as its own orphaned branch by a cron job over time in the format `YYYY-MM-DD-experiment-name`.

-------

# Archival notice

Fuzzbench proved to be so unreliable in its current state, even with community patches, that runs were not recoverable.
As such, this repo is archived.
